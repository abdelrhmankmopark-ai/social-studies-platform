# منصة الأستاذ محمد رمضان

منصة تعليمية لطلاب الصف الثاني الإعدادي.

## المواد
- الدراسات الاجتماعية
- الجغرافيا
- التاريخ

## المميزات
- إنشاء حساب لكل طالب.
- تسجيل الدخول والخروج.
- عرض الدروس التعليمية.
- روابط الفيديوهات وملفات PDF.
- اختبارات تفاعلية.
- تصحيح الاختبارات تلقائياً.
- حفظ نتائج الطلاب.
- لوحة تحكم للأستاذ.
- إدارة الطلاب والدروس والأسئلة.

## التقنيات
- HTML
- CSS
- JavaScript
- Firebase Authentication
- Cloud Firestore
- GitHub Pages

## إعداد Firebase

1. أنشئ مشروعاً في Firebase.
2. فعّل Authentication باستخدام Email/Password.
3. أنشئ قاعدة بيانات Cloud Firestore.
4. انسخ بيانات Firebase إلى:

`js/firebase-config.js`

5. انشر قواعد Firestore الموجودة في:

`firestore.rules`

6. أنشئ حساب الأستاذ.
7. غيّر قيمة role لحساب الأستاذ إلى admin في مستند المستخدم داخل Firestore.

## تشغيل الموقع

من إعدادات المستودع في GitHub:

Settings → Pages

اختر:

Deploy from a branch

ثم:

Branch: main

Folder: / (root)

واضغط Save.

## ملاحظة

GitHub Pages يستضيف ملفات الموقع فقط.
Firebase مسؤول عن الحسابات وقاعدة البيانات.

يجب اختبار صلاحيات الحسابات وقواعد البيانات قبل استخدام المنصة مع الطلاب.
